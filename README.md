# Портфолио лендингов FGIp02

Пять адаптивных учебных работ для разных бизнес-сценариев. Все персонажи, бренды и показатели демонстрационные. Формы не передают данные третьим лицам и показывают подтверждение локально в браузере.

## Локальный запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.
